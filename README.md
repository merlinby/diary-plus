# Дневник +

Android-приложение для diary.e-schools.by: полный официальный дневник в WebView, локальная аналитика оценок и два отдельных аккаунта учеников.

Текущая версия: **0.3.1**, Android 10+, target/compile API 35. Неофициальный личный проект.

## Продолжить в Codex

Откройте папку репозитория в Codex. Начните с `AGENTS.md` и `docs/CODEX_HANDOFF.md`: в них требования, архитектура, результаты проверок и следующие задачи. Git уже инициализирован, есть начальный коммит и тег `v0.3.1`. Удалённый репозиторий не подключён.

На Windows для приведённых shell-команд используйте WSL с Linux JDK и Android SDK внутри WSL. Это проект с ручной сборкой; стандартного Gradle/Android Studio проекта пока нет.

## Тесты

Нужны Node 22+ и JDK 17:

```bash
npm ci
npm test
bash scripts/test-native.sh
```

JS-тесты проверяют аналитику, автоподстановку и распознавание формы. JVM-тесты проверяют независимость метаданных профилей и AES-GCM. Они не заменяют запуск на Android.

## Сборка APK

Нужны JDK 17, Python 3, Android SDK Platform 35 и Build Tools 35.0.0. npm нужен только для JS-тестов.

Восстановите оригинальный ключ из отдельного приватного архива в каталог `signing/` рядом с `build.sh`. Архив содержит только два файла: release.jks и password.txt. Не добавляйте их в Git.

```bash
DIARY_SDK_DIR=/path/to/android-sdk bash build.sh
```

Нестандартные пути: `DIARY_BUILD_TOOLS_DIR`, `DIARY_PLATFORM_JAR`, `DIARY_SIGNING_DIR`. Результат: `release/DiaryPlus-0.3.1.apk`. Версия берётся из манифеста; перед изменением APK увеличьте versionCode/versionName.

Ключ обязателен для обновления уже установленного приложения. Скрипт не создаёт замену ключу автоматически. При отсутствии ключа завершается с понятной ошибкой.

## Поведение

- Кнопка профиля сверху: выбор ученика, переименование; сессии разделены.
- «Ещё → Вход и пароль»: логин и необязательное сохранение пароля.
- Пароли шифруются AES-GCM; ключ в Android Keystore требует системного подтверждения.
- Отпечаток/код нужен для доступа к паролю, а не для возврата в открытый дневник.
- Вход не отправляется автоматически: после подстановки нажмите «Войти».
- «Аналитика оценок»: год, четверть, период, оценки и средние.
- Push и офлайн-дневник не реализованы. Сам сайт работает по своим правилам.

## Перенос в удалённый Git

Создайте пустой приватный репозиторий у своего Git-провайдера, затем:

```bash
git remote add origin URL_ВАШЕГО_РЕПОЗИТОРИЯ
git push -u origin main
git push origin v0.3.1
```

APK, каталоги сборки, SDK, node_modules и материал подписи исключены из Git. Приватный архив ключа храните отдельно от репозитория.
