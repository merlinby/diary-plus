# Дневник +

Неофициальное Android-приложение для [diary.e-schools.by](https://diary.e-schools.by): полный сайт дневника в WebView, два профиля учащихся с отдельными сессиями и локальная аналитика оценок.

**Версия 0.3.1 · Android 10 и новее**

## Возможности

- Полный интерфейс официального дневника, включая работу с вложениями.
- Два профиля с независимыми сессиями, логинами и настройками сохранения пароля.
- Переключение и переименование профилей, открытие последнего выбранного профиля при запуске.
- Аналитика оценок по предметам за четверть, учебный год или выбранный период.
- Необязательное сохранение пароля и подстановка в форму входа без автоматической отправки.

## Установка

1. Откройте [последний релиз](https://github.com/merlinby/diary-plus/releases/latest) и скачайте APK из раздела **Assets**.
2. Установите APK на телефон. Если Android запросит разрешение на установку из этого источника, разрешите его для браузера или файлового менеджера, которым открываете файл.
3. Войдите в дневник со своей учётной записью diary.e-schools.by.

Исходники и релизы доступны публично. Контрольная сумма APK находится в файле `SHA256SUMS.txt` рядом со сборкой.

При обновлении используйте APK, подписанный тем же ключом, и устанавливайте его поверх предыдущей версии без удаления приложения, чтобы сохранить локальные настройки и сессии.

## Использование

- **Кнопка профиля вверху** — выбор и переименование учащегося. Во второй профиль нужно войти отдельно.
- **Ещё → Вход и пароль** — сохранение логина и, по желанию, пароля. Сохранение пароля по умолчанию выключено.
- **Аналитика оценок** — выбор периода и просмотр средних отметок.

После подстановки данных нажмите **«Войти»** вручную.

## Пароли и конфиденциальность

Пароли сохраняются только по желанию пользователя, в зашифрованном виде на устройстве. Используется AES-GCM с ключом Android Keystore и привязкой зашифрованной записи к профилю и логину.

Системное подтверждение отпечатком или кодом устройства используется при доступе к сохранённому паролю, его сохранении и редактировании. Обычное открытие уже авторизованного дневника, возврат из фона и переключение авторизованных профилей не требуют отдельной разблокировки приложения.

Пароль подставляется только на точном официальном HTTPS-источнике `https://diary.e-schools.by` и только для соответствующего логина. Приложение не отправляет форму входа автоматически.

Аналитика рассчитывается на устройстве по данным дневника. Собственного сервера и телеметрии у приложения нет.

## Ограничения

- Для работы с дневником и загрузки оценок нужен интернет. Офлайн-дневник и push-уведомления не реализованы.
- Средняя отметка — простое арифметическое, без весов и правил выставления итоговых оценок; она не заменяет официальную итоговую отметку.
- Границы четвертей ориентировочные и доступны для редактирования. Если дата урока неизвестна, аналитика учитывает всю неделю и показывает предупреждение.
- Работа зависит от доступности сайта и его интерфейсов. Изменения на стороне diary.e-schools.by могут потребовать обновления приложения.
- Проверка версии 0.3.1 на реальном устройстве, включая биометрию, сохранение сессий и переключение профилей, пока не завершена.

## Разработка

Приложение написано на Java; аналитика и автоподстановка реализованы в JavaScript. Используется ручная сборка без Gradle и AndroidX. Минимальная версия — Android 10 (API 29), target/compile — API 35, пакет — `by.local.diaryplus`.

### Тесты

Нужны Node.js 22+ и JDK 17. Команды рассчитаны на Linux; на Windows используйте WSL с Linux JDK. JVM-тест хранилища использует замену файлов с семантикой Linux.

```bash
npm ci
npm test
bash scripts/test-native.sh
```

JS-тесты проверяют аналитику, распознавание формы входа и автоподстановку. JVM-тесты проверяют независимость метаданных профилей и AES-GCM. Они не заменяют проверку WebView, Android Keystore, биометрии и реальных сессий на устройстве или эмуляторе.

### Сборка APK

Нужны Linux, Bash, JDK 17, Python 3, Android SDK Platform 35 и Build Tools 35.0.0. На Windows штатный `build.sh` запускайте в WSL с Linux JDK и Android SDK внутри WSL. npm нужен только для JS-тестов.

Скрипт требует ключ подписи `signing/release.jks` и файл пароля `signing/password.txt`. Для выпуска обновлений проекта восстановите оригинальные файлы из отдельной приватной резервной копии. Ключ автоматически не создаётся.

```bash
DIARY_SDK_DIR=/path/to/android-sdk bash build.sh
```

Дополнительные настройки путей:

| Переменная | Назначение |
| --- | --- |
| `DIARY_BUILD_TOOLS_DIR` | Каталог Build Tools |
| `DIARY_PLATFORM_JAR` | Путь к `android.jar` |
| `DIARY_SIGNING_DIR` | Каталог с `release.jks` и `password.txt` |

Результат — `release/DiaryPlus-<версия>.apk` и `release/SHA256SUMS.txt`. Версия берётся из `app/src/main/AndroidManifest.xml`; перед выпуском новой версии увеличьте `versionCode` и `versionName`.
